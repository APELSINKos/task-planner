# Changelog

Все заметные изменения проекта документируются в этом файле.

## [1.0.0] — 2026-11-26

### Добавлено
- Оригинальная дизайн-система Alpine Clarity (`Manrope` + `Golos Text`), светлая фарфоровая и тёмная графитовая темы с изумрудным акцентом и сохранением выбора в `localStorage`.
- Фирменные студийные растровые фоны (`frontend/images/*.webp`) для светлой и тёмной hero-сцены и блока авторизации, обновлённая иконка приложения (SVG + PNG 192/512) и Open Graph превью.
- Трёхэтапный `sticky scroll` сценарий на `requestAnimationFrame` с горизонтальной навигацией этапов, плавная глубина hero-окна и интерактивный мини-планировщик с фильтрацией по категориям и подзадачами в `motion.js` без внешних JS-библиотек.
- Быстрые клавиши в рабочей области: `/` для поиска и `N` для создания задачи (обе работают в EN и RU раскладке), `Tab`/`Shift+Tab` (focus trap), стрелочная навигация `tablist`, сохранение фокуса при переключении чекбоксов и `Escape` с возвратом фокуса в модальных окнах.
- Доступность WCAG 2.0 AA: контраст видимых текстов и кнопок ≥ 5.5:1 в обеих темах (включая кнопку удаления в тёмной теме — 6.47:1), состояния `aria-pressed` на фильтрах, touch targets ≥ 44×44 px, поддержка `prefers-reduced-motion: reduce`, модальное окно подтверждения вместо `confirm()`.
- Визуальная документация (`README.md` с адаптивной галереей и Mermaid-схемами) и расширенная проверка GitHub Actions CI для синхронизации статики, иконок и WebP-изображений между `frontend/` и `docs/`.

### Исправлено
- Устранены гонки запросов между `loadWorkspace()` и фильтрацией задач, блокировка кнопки «Сохранить» при повторном открытии модального окна и преждевременное закрытие редактора при отложенном сохранении.
- Исправлена контрастность счётчиков навигации в светлой теме (≥ 5.55:1 во всех темах), приведены к ≥ 44×44 px все интерактивные элементы на визитке, фильтрах и в песочнице.
- Адаптирована компоновка мобильного окна деталей на 390px (форма добавления подзадач без обрезки, кнопки действий в одну строку), исправлено позиционирование формы входа при переходе с кнопки «Войти» и кадрирование студийного фото.
- Устранена потеря клавиатурного фокуса при удалении подзадач и завершении задач в активном фильтре, исправлена работа горячих клавиш `/` и `N` сразу после чекбоксов и сброс индикатора прокрутки при `prefers-reduced-motion: reduce`.
- Добавлено удаление категорий в мобильной шторке и уважение заголовков `Cache-Control: no-store/private` в Service Worker (`sw.js`, кэш `v10`).

## [0.3.0] — 2026-11-23

### Добавлено
- Оркестрация стека через `docker-compose.yml`: PostgreSQL 16 (`pgdata`), FastAPI (non-root `appuser`), Nginx 1.27 (`:8080`) в изолированной сети `app-net` с цепочкой `healthcheck`.
- Динамический DNS-резолвер `127.0.0.11` в `nginx.conf` и таймауты проксирования для стабильной работы при перезапуске backend.
- Скрипты резервного копирования PostgreSQL (`scripts/backup_db.sh` и `scripts/backup_db.ps1`) с записью дампа без UTF-8 BOM.
- Сохранение сессии при временной недоступности сервера, откат чекбоксов при ошибке сети и расширенные граничные тесты `pytest` (8/8).
- Базовый workflow GitHub Actions CI для прогона `pytest` (SQLite + PostgreSQL 16), валидации `docker-compose.yml` и проверки синхронности статики `frontend/` и `docs/`.

## [0.2.0] — 2026-11-20

### Добавлено
- Семантический адаптивный веб-интерфейс (HTML5, CSS3/БЭМ, Flexbox/Grid, mobile-first).
- Интеграция с REST API через `Fetch API` (`async/await`, `try/catch`, состояния `loading`, `empty`, `error`, обработка `401`).
- PWA-манифест (`manifest.webmanifest`), иконки 192×192 и 512×512, Service Worker (`sw.js`).
- Автономная демо-версия на GitHub Pages (`docs/`) с локальным хранилищем браузера.

## [0.1.0] — 2026-11-13

### Добавлено
- Реляционная схема PostgreSQL 16 в 3НФ (`users`, `categories`, `tasks`, `subtasks`) с `ON DELETE SET NULL` для категорий и `ON DELETE CASCADE` для подзадач.
- Синхронный REST API на FastAPI + SQLAlchemy 2 + Pydantic v2 (18 эндпоинтов + Swagger UI `/docs` с русскоязычными описаниями всех 5 групп и маршрутов).
- Аутентификация Bearer JWT (HS256, 24 ч), хеширование паролей `bcrypt` (12 раундов) и изоляция данных по `user_id`.
- Набор автотестов `pytest` и исправления по результатам Code-Review (проверка длины пароля ≤ 72 байт UTF-8, экранирование `ILIKE`, обработка `IntegrityError`, проверка противоречивых `status`/`is_completed`).
